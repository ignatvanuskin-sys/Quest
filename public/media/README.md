# Медиа NOX

Все визуальные фоны подключены из локальной папки `МЕДИА КОНТЕНТ`,
оптимизированы (кроп под формат + JPEG q82) скриптом `tools/optimize-media.ps1`
и разложены здесь с ASCII-именами.

с непрозрачным фоном, статической секции брони на странице нет.

## Процедурный фолбэк

`components/QuestArt.tsx` по-прежнему умеет рисовать процедурный арт
(градиенты + туман + зерно) — он используется как фолбэк, если у сущности
не задан `imageSrc`.

## Замена на реальный контент

Положите свои файлы с теми же именами (или поправьте пути в `lib/quests.ts`
и компонентах) и при необходимости перегенерируйте кропы скриптом
`tools/optimize-media.ps1`.
